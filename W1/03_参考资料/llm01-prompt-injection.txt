LLM01:2025 快速注射
当用户提示以非预期的方式改变LLM的行为或输出时，就会发生提示注入漏洞。这些输入即使对人类来说是不可察觉的，也可能影响模型，因此，只要模型能够解析提示内容，提示注入的内容就不需要对人类可见/可读。

提示注入漏洞存在于模型处理提示的方式中，输入可能迫使模型错误地将提示数据传递给模型的其他部分，从而导致模型违反准则、生成有害内容、允许未经授权的访问或影响关键决策。虽然检索增强生成 (RAG) 和微调等技术旨在使 LLM 的输出更具相关性和准确性，但研究表明，它们并不能完全缓解提示注入漏洞。

虽然提示注入和越狱是LLM安全领域的相关概念，但它们经常被混用。提示注入是指通过特定输入操纵模型响应以改变其行为，包括绕过安全措施。越狱是提示注入的一种形式，攻击者提供的输入会导致模型完全无视其安全协议。开发人员可以在系统提示和输入处理中构建安全措施来帮助缓解提示注入攻击，但要有效防止越狱，则需要持续更新模型的训练和安全机制。

提示注入漏洞的类型


直接快速注射
直接提示注入是指用户的提示输入直接以非预期或意想不到的方式改变模型的行为。这种输入可能是故意的（例如，恶意行为者故意构造提示来利用模型），也可能是无意的（例如，用户无意中提供的输入触发了意外行为）。

间接快速注射
间接提示注入是指逻辑学习模型（LLM）接受来自外部来源（例如网站或文件）的输入。外部内容中可能包含一些数据，当模型解读这些数据时，会以意想不到的方式改变模型的行为。与直接注入类似，间接注入也可能是有意的，也可能是无意的。

成功的即时注入攻击所造成影响的严重程度和性质可能差异很大，并且很大程度上取决于模型运行的业务环境以及设计该模型的机构。但通常来说，即时注入会导致一些意想不到的后果，包括但不限于：

敏感信息的披露
泄露有关人工智能系统基础设施或系统提示的敏感信息
内容操纵导致错误或有偏见的输出
未经授权访问LLM可用的功能
在联网系统中执行任意命令
操纵关键决策过程
多模态人工智能的兴起，使其能够同时处理多种数据类型，但也带来了独特的提示注入风险。恶意攻击者可以利用不同模态之间的交互作用，例如将指令隐藏在看似无害的文本所附带的图像中。这些系统的复杂性扩大了攻击面。多模态模型也可能容易受到新型跨模态攻击，而这些攻击难以用现有技术进行检测和缓解。因此，开发强大的多模态专用防御机制是未来研究和开发的重要方向。

预防和缓解策略
由于生成式人工智能的特性，可能存在提示注入漏洞。鉴于模型运行的核心在于随机性，目前尚不清楚是否存在万无一失的提示注入防范方法。然而，以下措施可以减轻提示注入的影响：

1. 约束模型行为
在系统提示中提供关于模型角色、功能和局限性的具体说明。强制模型严格遵守上下文，限制其对特定任务或主题的响应，并指示模型忽略任何修改核心指令的尝试。

2. 定义并验证预期输出格式
明确指定输出格式，要求提供详细的推理和来源引用，并使用确定性代码来验证是否符合这些格式。

3. 实现输入输出滤波
定义敏感类别并构建规则以识别和处理此类内容。应用语义过滤器并使用字符串检查来扫描不允许的内容。使用 RAG 三元组评估响应：评估上下文相关性、依据性和问答相关性，以识别潜在的恶意输出。

4. 强制执行权限控制和最小权限原则
为应用程序提供其自身的 API 令牌以实现可扩展功能，并在代码中处理这些功能，而不是将其提供给模型。将模型的访问权限限制在执行其预期操作所需的最低限度。

5. 高风险行为需经人工批准
对特权操作实施人机交互控制，以防止未经授权的操作。

6. 区分并识别外部内容
将不受信任的内容单独列出并明确标示，以限制其对用户提示的影响。

7. 进行对抗性测试和攻击模拟\
定期进行渗透测试和入侵模拟，将模型视为不受信任的用户，以测试信任边界和访问控制的有效性。

攻击场景示例
方案一：直接注射
攻击者向客户支持聊天机器人注入提示，指示其忽略之前的准则，查询私有数据存储，并发送电子邮件，从而导致未经授权的访问和权限提升。

情景二：间接注射
用户使用 LLM 来概括包含隐藏指令的网页，这些指令会导致 LLM 插入链接到 URL 的图像，从而导致私人对话泄露。

情景三：意外注射
一家公司在职位描述中加入了一项说明，旨在识别人工智能生成的申请。一位求职者并不知道这项说明，他使用招聘管理软件（LLM）优化了自己的简历，无意中触发了人工智能的检测机制。

情景四：有意影响模型
攻击者篡改了检索增强生成 (RAG) 应用程序所用存储库中的文档。当用户的查询返回修改后的内容时，恶意指令会改变 LLM 的输出，从而生成误导性结果。

场景五：代码注入
攻击者利用 LLM 驱动的电子邮件助手中的一个漏洞 (CVE-2024-5184) 注入恶意提示，从而访问敏感信息并操纵电子邮件内容。

场景 6：有效载荷分割
攻击者上传了一份包含恶意提示信息的简历。当使用学习领导力模型（LLM）评估候选人时，这些组合提示信息会操纵模型的响应，导致模型给出积极的推荐，而这与简历的实际内容不符。

场景七：多模式注射
攻击者将恶意提示嵌入到一张看似无害的文本图片中。当多模态人工智能同时处理图片和文本时，隐藏的提示会改变模型的行为，可能导致未经授权的操作或敏感信息的泄露。

场景 8：对抗性后缀
攻击者向提示符附加看似毫无意义的字符串，从而恶意影响 LLM 的输出，绕过安全措施。

场景 9：多语言/混淆攻击
攻击者使用多种语言或对恶意指令进行编码（例如，使用 Base64 或表情符号）来规避过滤器并操纵 LLM 的行为。
