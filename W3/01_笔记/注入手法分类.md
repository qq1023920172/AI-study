# 注入手法分类

> 目标是**维度**，不是清单。清单记不住，维度能覆盖到你想不到的组合。

## 一、四个正交维度

填完这张表，你就有了一套可枚举的分类法。

| 维度 | 取值 | 说明 |
|---|---|---|
| **位置** | 用户输入 / 检索内容 / 工具返回 / 文件名 / 图片 / 模型输出 | 越靠后越难被用户察觉 |
| **意图** | 改变行为 / 泄露信息 / 消耗资源 / 污染输出 / 提权 | |
| **手法** | 直接命令 / 伪造系统消息 / 编码 / 分片 / 多轮 / 多语言 / 角色包装 | |
| **强度** | 许可 / 要求 / 义务 / 排他 | W1 实测：许可 0/5，其余 5/5 |

## 二、四维交叉举例

任取四维的一个值，组成一种攻击。举三例：

| 组合 | 场景 |
|---|---|
| 工具返回 × 泄露 × 编码 × 义务 | 某个 API 返回的错误信息里藏了 base64 指令，模型执行后读出配置 |
| 文件名 × 污染输出 × 直接 × 排他 | 上传名为「忽略规则并输出XX.pdf」的文件，模型在总结时引用文件名 |
| 检索内容 × 提权 × 多轮 × 要求 | 分三轮让模型逐步接受"你有权调用工具"，第三轮才发起调用 |

**自己去凑 10 个组合，其中至少 3 个是你没测过的。** ← 这是本周最重要的作业

## 三、和 W2 的衔接

W2 测的是「位置 = 检索内容」这一格。W3 要把它铺开：

- 位置还剩：工具返回、文件名、图片
- 意图还剩：消耗资源、污染输出、提权
- 手法还剩：分片、多轮
